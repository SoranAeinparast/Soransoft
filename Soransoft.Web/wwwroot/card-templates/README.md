# قالب کارت شناسایی همکاران

فایل کارت خام را با نام `partner-id-card.jpg` در همین پوشه قرار دهید.

پس از دریافت تصویر، محل عکس، QR و متن‌ها بر اساس ابعاد واقعی تصویر در `IdentityCardController` تنظیم می‌شود. فایل خام فقط قالب گرافیکی است و اطلاعات همکار هنگام درخواست کارت از دیتابیس روی یک نسخه خروجی جدید درج می‌شود.
